Guide Complet d'Hébergement & Firebase

Comment déployer gratuitement Wiki Game sur GitHub Pages avec votre propre base de données.

1. Configuration du Projet Firebase (Gratuit)

  1. Rendez-vous sur la Console Firebase et cliquez sur "Ajouter un projet" nommé wiki-game.
  2. Dans le menu de gauche, allez dans Build > Authentication. Activez la méthode "E-mail / Mot de passe".
  3. Dans le menu Build > Firestore Database, créez une base de données en Mode Production.

2. Configuration des Règles de Sécurité Firestore

Copiez ces règles dans l'onglet Firestore > Rules pour sécuriser l'accès :

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read: if true;
      allow write: if request.auth != null && request.auth.uid == userId;
    }
    match /games/{gameId} {
      allow read: if true;
      allow write: if request.auth != null && get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }
    match /articles/{articleId} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null && (resource.data.authorId == request.auth.uid || get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin');
    }
    match /comments/{commentId} {
      allow read: if true;
      allow create: if request.auth != null;
      allow delete: if request.auth != null && (resource.data.userId == request.auth.uid || get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin');
    }
  }
}

3. Configuration de votre compte Administrateur

Créer votre rôle administrateur en 2 clics :

  1. Inscrivez-vous normalement sur ce site.
  2. Ouvrez le modal "Admin Setup" ou entrez la clé de passe administrateur par défaut dans le panneau administrateur (WIKIGAME-ADMIN-SECRET).
  3. Votre profil basculera immédiatement en rôle ADMIN.

4. Publication sur GitHub Pages

  1. Créez un nouveau dépôt public sur GitHub nommé wiki-game.
  2. Déposez ce fichier index.html à la racine du dépôt.
  3. Dans votre dépôt GitHub, allez dans Settings > Pages.
  4. Sous Branch, sélectionnez main (ou master) et enregistrez.
  5. Votre site sera accessible en ligne gratuitement sur : https://votre-pseudo.github.io/wiki-game/ !
